## Brand & Style

This design system delivers an executive-tier, document-intelligence experience centered around quiet confidence, clarity, and precision. It caters to legal counsels, enterprise administrators, operations leaders, and high-output knowledge workers who handle mission-critical records. The emotional response is one of absolute control, cognitive calm, and institutional trust.

The design movement combines **Minimalism** with **Modern Enterprise Utility**. The canvas is white-first and spacious. High-contrast typography pairs with immaculate structural borders to replace visual noise with crisp organization. Color is employed with surgical restraint: primary indigo-violet acts purely as an interaction signifier and precise brand anchor, while soft slate blues highlight system metadata. Tinted blocks and heavy decorative fills are rejected in favor of pure white planes, fine-line delineation, and clear typographic hierarchy.

## Colors

The palette establishes an architectural, high-clarity environment where pure white surfaces dominate and brand colors provide decisive orientation.

### Core Roles
- **Canvas Base (`#F7F8FC`)**: Ambient canvas backdrop that provides subtle separation behind elevated white cards and working panels.
- **Surface Pure (`#FFFFFF`)**: Dominant container color for all content blocks, sheets, toolbars, and inspection panels.
- **Primary Violet (`#6254C7`)**: The definitive brand anchor. Strictly reserved for primary calls-to-action, key active indicators, and critical focus states.
- **Primary Violet Dark (`#4F43AD`)**: Hover, pressed, and high-emphasis states for primary actions.
- **Violet Subtle Tint (`#EAE8FA`)**: High-priority selection outlines, chip borders, and active nav item backgrounds.
- **Violet Wash (`#F5F3FC`)**: Very light tinted background for active rows or subtle document drop targets.
- **Secondary Blue (`#477DAF`)**: Secondary metadata, technical tags, document version badges, and non-actionable status telemetry.
- **Blue Subtle (`#EAF2FC`) & Blue Wash (`#F3F8FD`)**: Metadata badges, file-extension indicators, and auxiliary information containers.

### Typography & Structure
- **Text Primary (`#25243A`)**: Deep ink tone providing uncompromising contrast for headlines, metrics, and core document metadata.
- **Text Secondary (`#747587`)**: Supportive descriptions, secondary labels, and column headers.
- **Text Muted (`#9698A8`)**: Timestamps, breadcrumb dividers, disabled elements, and placeholder values.
- **Structural Border (`#E6E7EF`)**: Defines cards, headers, sidebars, and input outlines.
- **Divider (`#ECECF2`)**: Fine internal cell separators and list item boundaries.

### Semantic Status
- **Success (`#278A68`)**: Confirmed signatures, verified OCR runs, and synced archives.
- **Warning (`#C58A35`)**: Pending reviews, access expirations, and unverified data fields.
- **Error (`#C94E5B`)**: Processing failures, access denials, and validation blocks.

## Typography

The typography system relies on **Manrope** across all display, body, and UI label roles, supplemented by **JetBrains Mono** strictly for verification hashes, optical OCR bounding-box coordinates, and file checksums.

Manrope delivers geometric clarity with open counters and balanced structural proportions, ensuring dense table views, multi-page document trees, and executive dashboards remain effortless to scan. Numeric figures default to tabular alignment (`tnum`) in data tables and metadata strips. All uppercase labels apply subtle tracking (`0.04em`) to preserve legibility at compact dimensions.

## Layout & Spacing

The layout is anchored in an 8-point rhythmic grid with a 4-point sub-grid for internal component micro-spacing.

### Layout Model
- **Desktop (≥ 1280px)**: 12-column fluid grid, 24px gutters, 32px canvas margins. Global master-detail view utilizes a collapsible 260px navigation bar, a 360px contextual index panel, and a fluid main document canvas.
- **Tablet (768px – 1279px)**: 8-column layout, 16px gutters, 24px canvas margins. Secondary metadata sheets become drawer-based overlays to maintain central document readability.
- **Mobile (< 768px)**: 4-column layout, 16px gutters, 16px canvas margins. Navigational structures collapse into a fixed bottom action bar and responsive sheets.

### Spacing Principles
Whitespace conveys structural hierarchy rather than decorative emptiness. Container padding respects density: tables and inspector panels rely on compact rhythm (`space-sm` to `space-md`), whereas overview pages and empty states leverage broader breathing room (`space-xl` to `space-2xl`).

## Elevation & Depth

This design system uses **flat architectural layering with low-contrast outlines** and minimal ambient shadows. Depth is achieved primarily through surface shifts rather than drop shadows.

- **Level 0 (Canvas Base)**: `#F7F8FC`. The foundation layer.
- **Level 1 (Structural Surface)**: `#FFFFFF` surrounded by a 1px border of `#E6E7EF`. No drop shadow. Used for table wrappers, main document review viewports, and primary structural cards.
- **Level 2 (Floating Overlays & Menus)**: `#FFFFFF` surface with a 1px border of `#E6E7EF` and an ambient, low-opacity shadow: `0 4px 16px -2px rgba(37, 36, 58, 0.06), 0 2px 6px -1px rgba(37, 36, 58, 0.03)`. Used for dropdowns, popovers, and contextual toolbars.
- **Level 3 (Modal Dialogs & Command Bars)**: `#FFFFFF` surface with a crisp border of `#E6E7EF` and a diffused shadow: `0 12px 32px -4px rgba(37, 36, 58, 0.10), 0 4px 12px -2px rgba(37, 36, 58, 0.04)`. Paired with a backdrop dim of `#25243A` at 25% opacity.

## Shapes

The shape system adopts a **Rounded** profile (`level 2`), setting standard corner radiuses to 8px (`0.5rem`). This provides balanced modernity without sliding into casual toy-like circularity.

- **Base Radius (8px / `0.5rem`)**: Default for standard buttons, text input boxes, dropdown selectors, and small notification toasts.
- **Container Radius (12px to 16px / `rounded-lg` to `rounded-xl`)**: Document preview cards, elevated modals, and content wrapper panels.
- **Compact Radius (4px / `rounded-sm`)**: Data chips, file-extension indicators, and internal table selection tags.
- **Strictly Square (0px)**: The internal rendered PDF/document viewport canvas, emphasizing strict legal record integrity.

## Components

### Buttons
- **Primary**: Solid background `#6254C7`, text `#FFFFFF`, font weight 600. Hover: `#4F43AD`. Active: `#3F348F`. Border: none. Focus ring: 2px offset with `#6254C7`.
- **Secondary**: Surface `#FFFFFF`, border 1px solid `#E6E7EF`, text `#25243A`. Hover: background `#F7F8FC`, border `#747587`.
- **Ghost/Tertiary**: Surface transparent, text `#747587`. Hover: background `#F5F3FC`, text `#6254C7`.
- **Destructive**: Surface `#FFFFFF`, border 1px solid `#E6E7EF`, text `#C94E5B`. Hover: background `#FFF5F5`, border `#C94E5B`.

### Input Fields & Controls
- **Text Inputs**: Background `#FFFFFF`, border 1px solid `#E6E7EF`, text `#25243A`, placeholder `#9698A8`, height 40px, padding 0 12px. Focus: border 1px solid `#6254C7`, outline 2px solid `#EAE8FA`.
- **Checkboxes & Radios**: 18px square/circle. Unchecked: border 1.5px solid `#E6E7EF`, background `#FFFFFF`. Checked: background `#6254C7`, checkmark icon `#FFFFFF`. Focus: ring 2px solid `#EAE8FA`.

### Chips & Badges
- **Status Badges**: Padding 2px 8px, border-radius 4px, font size 11px, weight 600, uppercase.
  - *Processed/Verified*: Background `#EDF7F3`, border 1px solid `#B8E3D3`, text `#278A68`.
  - *Metadata/Version*: Background `#F3F8FD`, border 1px solid `#EAF2FC`, text `#477DAF`.
  - *Action Required*: Background `#FEF8EC`, border 1px solid `#F7E4BE`, text `#C58A35`.
- **Filter Chips**: Height 28px, background `#FFFFFF`, border 1px solid `#E6E7EF`, text `#747587`. Active state: background `#F5F3FC`, border 1px solid `#6254C7`, text `#6254C7`.

### Cards & Document Cells
- **Cards**: Background `#FFFFFF`, 1px solid `#E6E7EF`, border-radius 12px. Padding 16px or 24px. Hover state for interactive cards adds 1px solid `#6254C7` border with zero layout shift.
- **List & Table Rows**: Cell padding 12px 16px, bottom border 1px solid `#ECECF2`. Hover: background `#F7F8FC`. Selected row: background `#F5F3FC`, left accent indicator 3px solid `#6254C7`.

### Document Inspection Panel (Specialized)
- Fixed right-hand rail, background `#FFFFFF`, left border 1px solid `#E6E7EF`. Header contains document name in `headline-sm` with a secondary blue file-type pill (`#F3F8FD`). Property rows utilize a two-column key-value pattern: keys in `#747587` (`body-sm`), values in `#25243A` (`label-md`).
